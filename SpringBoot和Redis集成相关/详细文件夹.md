## 以一问一答的形式

* Q1 : 什么是Redis？为什么要在Spring Boot项目中集成Redis?
* A1 : Redis（Remote Dictionary Server）是一个开源的、基于内存的高性能键值存储系统、支持多种数据结构(如String、Hash、Set、List、ZSet)，常用于缓存、会话管理、消息队列、排行榜等场景。
  在Spring Boot项目中集成Redis中有以下目的:

  * 提升系统性能：通过缓存热点数据，减少数据库压力
  * 提高响应速度: 内存读写远快于磁盘 I/O
  * 分布式共享状态:多个服务实例可以共享同一份缓存数据
  * 实现高并发控制：如分布式锁、限流
* Q2: Spring Boot 如何集成Redis？需要哪些依赖
* A2:
  Spring Boot 官方提供了对Redis的自动装配支持下，主要依赖如下:

  ```xml
  <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-data-redis</artifactId>
  </dependency>

  <!-- 如果使用 Lettuce 以外的客户端（如 Jedis），需额外引入 -->
  <!-- 默认使用 Lettuce（基于 Netty，支持响应式） -->
  ```

  此外，若需要连接池还需要添加:

  ```xml
  <dependency>
      <groupId>org.apache.commons</groupId>
      <artifactId>commons-pool2</artifactId>
  </dependency>
  ```
* Q3: 如何配置Redis连接信息
* A3：在Yaml中配置

  ```yml
  spring:
    redis:
      host: localhost
      port: 6379
      password: ""          # 若有密码
      database: 0
      timeout: 2000ms
      lettuce:
        pool:
          max-active: 8
          max-idle: 8
          min-idle: 0
          max-wait: -1ms
  ```

  Spring Boot 会自动创建 `RedisConnectionFactory`、`RedisTemplate`和 `StringRedisTemplate`等Bean。
* Q4: RedisTemplate和StringRedisTemplate有什么区别
* A4:
  前者是泛型的，后者是估计String类型的
* Q5：如何自定义RedisTemplate是序列化方式？
* A5:
  可以通过配置类覆盖默认的	`RedisTemplate`：

  ```java
  @Configuration
  public class RedisConfig {

      @Bean
      public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
          RedisTemplate<String, Object> template = new RedisTemplate<>();
          template.setConnectionFactory(factory);

          // 使用 String 序列化 key
          template.setKeySerializer(new StringRedisSerializer());
          template.setHashKeySerializer(new StringRedisSerializer());

          // 使用 JSON 序列化 value（需引入 Jackson）
          Jackson2JsonRedisSerializer<Object> jsonSerializer = 
              new Jackson2JsonRedisSerializer<>(Object.class);
          template.setValueSerializer(jsonSerializer);
          template.setHashValueSerializer(jsonSerializer);

          template.afterPropertiesSet();
          return template;
      }
  }
  ```

  这样存储的存储对象以JSON格式保存
* Q6：如何使用Redis实现缓存?Spring Cache 如何于Redis结合?
* A6:
  Spring 提供了声明式缓存抽象（`@Cacheable`,`@CachePut`,`@CacheEvict`）,配合Redis可以轻松实现缓存。
  步骤：

  * 启用缓存:

    ```java
    @EnableCaching
    @SpringBootApplication
    public class Application { ... }
    ```
  * 在方法上使用注释:

    ```java
    @Cacheable(value = "users", key = "#id")
    public User getUserById(Long id) {
        // 查询数据库
    }

    @CacheEvict(value = "users", key = "#id")
    public void deleteUser(Long id) {
        // 删除数据库记录
    }
    ```
* Q7: 如何处理缓存穿透、缓存击穿、缓存雪崩？
* A7：

  * 缓存穿透 ，查询不存在的数据，绕过缓存直接DB ， 1.布隆过滤器拦截无效请求  2.缓存空值（设置短TTL）
  * 缓存击穿，热点Key过期瞬间大量请求打到DB，1.设置永不过期（逻辑过期）2.使用互斥锁（如Redis分布式锁）重建缓存
  * 缓存雪崩 ，大量Key同时过期，DB瞬间压力剧增 ，1.设置随机TTL（如base+random）2.多级缓存（本地+Redis）3.限流降级
* Q8如何使用Redis实现分布式锁？
* A8：
  推荐使用Redis的 `SET key Value NX PX` 命令（原子操作）：

  ```java
  public boolean tryLock(String lockKey, String requestId, long expireTime) {
      Boolean result = redisTemplate.execute(
          (RedisCallback<Boolean>) connection ->
              connection.set(lockKey.getBytes(),
                            requestId.getBytes(),
                            Expiration.milliseconds(expireTime),
                            RedisStringCommands.SetOption.SET_IF_ABSENT)
      );
      return Boolean.TRUE.equals(result);
  }

  public boolean releaseLock(String lockKey, String requestId) {
      String script = "if redis.call('get', KEYS[1]) == ARGV[1] then return redis.call('del', KEYS[1]) else return 0 end";
      Long result = redisTemplate.execute(
          new DefaultRedisScript<>(script, Long.class),
          Collections.singletonList(lockKey),
          requestId
      );
      return result != null && result == 1L;
  }
  ```
* Q9 : Lettuce 和 Jedis有什么区别？Spring Boot
* A9 :

  * Jedis,非线程安全，需连接池，单连接单线程，每个线程需要独立的连接
  * Lettuce , 线程安全，基于Netty，共享连接
* Q10 : 如何监控和调试Redis操作？
* A10 ：

  * 开启日志：配置 `logging.level.org.springframwork.data.redis=DEBUG`
  * 使用Redis CLI ： `redis-climonitor` 实时查看命令
  * 可视化工具 ：RedisInsight 、Another Redis Desktop Manager
  * 指标监控： 通过Micrometer + Prometheus 监控 Redis连接池、命中率
