## 问题集合

### 字体问题

* 代码执行的地方是Linux服务器，之前在windos做开发的时候没有遇到过由于字体问题导致的渲染的富文本页面内容汉字部分是空白的情况
* 解决过程:
  * 首次尝试，在包裹在富文本外包的html文件头中， 设置 font-family属性，尝试设置为系统中存在的汉字字体，失败
  * 再次尝试，直接给渲染的ITextFontResolver fontResolver 对象设置字体

    ```java
    ITextFontResolver fontResolver = renderer.getFontResolver();
    fontResolver.addFont("/usr/share/fonts/vlgothic/simhei.ttf",
    	BaseFont.IDENTITY_H,
    	BaseFont.NOT_EMBEDDED
    );
    ```

    第二次尝试解决了字体问题

### 依赖冲突问题

* 在解决问题的方案里面，存在依赖和系统里面其他功能冲突的情况
* 解决方法:
  放弃了将，富文本转图片的功能集成到系统中，将该功能打包为一个jar包（和其他依赖一起），调用的时候，主程序通过调用jar包的方式调用该功能。

### 主线程调用性能问题

* 使用主线程调用jar包的方式出现了该子线程的卡住的情况，判断是因为主线程本身的资源不够，修改了以下调用方式

  ```java
  ProcessBuilder pb = new ProcessBuilder("bash","-c","java -jar /home/service/html-to-image-service.jar");
  pb.redirectErrorStream(true);
  Process process = pb.start();
  ```

  修复该bug的核心就是要及时消费掉子线程任务的输出**输出流（stdout/stderrs)***  **子进程（**`java -cp ...`）向 stdout 或 stderr 写入数据时，如果父进程（你的 Java 程序）不及时读取， **缓冲区会填满并阻塞子进程** **，导致它“卡住”，看起来像“很慢”或“没反应”****Linux 下管道（pipe）默认缓冲区很小（通常 4KB~64KB），一旦写满，写入方就会**  **阻塞等待读取** **。**
