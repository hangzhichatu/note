## 第1章 函数式接口基础
* 1.1 什么是函数式接口？
```java 
/**
 * 函数式接口定义：
 * 只包含一个抽象方法的接口
 */
@FunctionalInterface
@FunctionalInterface  // 可选注解，编译器会检查
public interface Runnable {
    void run();  // 唯一的抽象方法
}
```
```txt
┌─────────────────────────────────────────────────────────────────┐
│                    函数式接口规则                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ✅ 允许：                                                     │
│   • 一个抽象方法                                               │
│   • 任意数量的 default 方法                                     │
│   • 任意数量的 static 方法                                      │
│   • Object 类的方法（equals, hashCode, toString）               │
│                                                                 │
│   ❌ 不允许：                                                   │
│   • 两个或以上的抽象方法                                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
* 1.2 函数式接口的实例化方式
```java
@FunctionalInterface
interface MyFunction {
    void execute();
}

public class Demo {
    
    // ═══════════════════════════════════════════════════════════
    // 方式1: 匿名内部类（JDK 8 之前）
    // ═══════════════════════════════════════════════════════════
    MyFunction f1 = new MyFunction() {
        @Override
        public void execute() {
            System.out.println("执行");
        }
    };
    
    // ═══════════════════════════════════════════════════════════
    // 方式2: Lambda 表达式（JDK 8+ 推荐）
    // ═══════════════════════════════════════════════════════════
    MyFunction f2 = () -> System.out.println("执行");
    
    // ═══════════════════════════════════════════════════════════
    // 方式3: 方法引用（最简洁）
    // ═══════════════════════════════════════════════════════════
    MyFunction f3 = this::doWork;
    
    public void doWork() {
        System.out.println("执行");
    }
    
    // 三种方式完全等价！
}
```

* 2.2 Runnable - 无参无返回
样例代码:
```java
/**
 * 用途：表示一个可执行的任务，无参数无返回值
 * 典型场景：线程任务、回调
 */
public class RunnableDemo {
    
    public static void main(String[] args) {
        
        // ═══════════════════════════════════════════════════════
        // 场景1: 创建线程
        // ═══════════════════════════════════════════════════════
        Thread thread = new Thread(() -> {
            System.out.println("线程执行中...");
        });
        thread.start();
        
        // ═══════════════════════════════════════════════════════
        // 场景2: 延迟执行
        // ═══════════════════════════════════════════════════════
        Runnable task = () -> System.out.println("延迟任务");
        new Timer().schedule(new TimerTask() {
            @Override
            public void run() {
                task.run();
            }
        }, 1000);
        
        // ═══════════════════════════════════════════════════════
        // 场景3: 方法参数传递行为
        // ═══════════════════════════════════════════════════════
        executeWithLogging(() -> doWork());
    }
    
    static void doWork() {
        System.out.println("工作中...");
    }
    
    static void executeWithLogging(Runnable task) {
        System.out.println("开始执行");
        long start = System.nanoTime();
        task.run();
        long end = System.nanoTime();
        System.out.println("执行完成，耗时: " + (end - start) / 1_000_000 + "ms");
    }
}
```
* 2.3 Supplier - 无参有返回
```java
/**
 * 用途：供应者，无参数，返回一个值
 * 典型场景：工厂模式、懒加载、生成随机值
 */
public class SupplierDemo {
    
    public static void main(String[] args) {
        
        // ═══════════════════════════════════════════════════════
        // 场景1: 工厂模式
        // ═══════════════════════════════════════════════════════
        Supplier<User> userFactory = () -> new User("张三", 18);
        User user = userFactory.get();
        
        // ═══════════════════════════════════════════════════════
        // 场景2: 懒加载
        // ═══════════════════════════════════════════════════════
        Supplier<List<String>> lazyList = () -> {
            System.out.println("正在加载数据...");
            return loadFromDatabase();
        };
        // 只有调用 get() 时才会真正加载
        List<String> data = lazyList.get();
        
        // ═══════════════════════════════════════════════════════
        // 场景3: 生成随机值
        // ═══════════════════════════════════════════════════════
        Supplier<Integer> randomSupplier = () -> new Random().nextInt(100);
        System.out.println(randomSupplier.get());  // 每次调用都不同
        
        // ═══════════════════════════════════════════════════════
        // 场景4: Optional.ofNullable + Supplier
        // ═══════════════════════════════════════════════════════
        String value = null;
        String result = Optional.ofNullable(value)
            .orElseGet(() -> "默认值");  // 只有 value 为 null 时执行
        
        // ═══════════════════════════════════════════════════════
        // 场景5: 基本类型特化（避免装箱）
        // ═══════════════════════════════════════════════════════
        IntSupplier intSupplier = () -> new Random().nextInt();
        LongSupplier longSupplier = () -> System.currentTimeMillis();
        DoubleSupplier doubleSupplier = () -> Math.random();
    }
    
    static class User {
        String name;
        int age;
        User(String name, int age) { this.name = name; this.age = age; }
    }
    
    static List<String> loadFromDatabase() {
        return Arrays.asList("数据1", "数据2", "数据3");
    }
}
```

* 2.4 Consumer - 有参无返回
```java
/**
 * 用途：消费者，接收一个参数，无返回值
 * 典型场景：数据处理、打印、写入
 */
public class ConsumerDemo {
    
    public static void main(String[] args) {
        
        // ═══════════════════════════════════════════════════════
        // 场景1: 集合遍历
        // ═══════════════════════════════════════════════════════
        List<String> list = Arrays.asList("A", "B", "C");
        list.forEach(s -> System.out.println(s));  // Consumer<String>
        
        // ═══════════════════════════════════════════════════════
        // 场景2: 链式消费（andThen）
        // ═══════════════════════════════════════════════════════
        Consumer<String> printer = s -> System.out.println("打印: " + s);
        Consumer<String> logger = s -> System.out.println("日志: " + s);
        
        // 先打印再记录日志
        printer.andThen(logger).accept("消息");
        
        // ═══════════════════════════════════════════════════════
        // 场景3: 构建器模式
        // ═══════════════════════════════════════════════════════
        User user = new User();
        configureUser(u -> u.setName("张三"),
                      u -> u.setAge(18),
                      u -> u.setEmail("test@example.com"));
        
        // ═══════════════════════════════════════════════════════
        // 场景4: 基本类型特化
        // ═══════════════════════════════════════════════════════
        IntConsumer intConsumer = x -> System.out.println("数字: " + x);
        intConsumer.accept(42);
        
        LongConsumer longConsumer = x -> System.out.println("长整型: " + x);
        DoubleConsumer doubleConsumer = x -> System.out.println("双精度: " + x);
    }
    
    static class User {
        String name;
        int age;
        String email;
        void setName(String n) { name = n; }
        void setAge(int a) { age = a; }
        void setEmail(String e) { email = e; }
    }
    
    @SafeVarargs
    static void configureUser(User user, Consumer<User>... configures) {
        for (Consumer<User> c : configures) {
            c.accept(user);
        }
    }
}
```

* 2.5 Function<T,R> - 有参有返回
```java
/**
 * 用途：函数，接收一个参数，返回一个值
 * 典型场景：数据转换、映射
 */
public class FunctionDemo {
    
    public static void main(String[] args) {
        
        // ═══════════════════════════════════════════════════════
        // 场景1: 数据转换
        // ═══════════════════════════════════════════════════════
        Function<String, Integer> strToInt = s -> Integer.parseInt(s);
        Integer num = strToInt.apply("123");
        
        // ═══════════════════════════════════════════════════════
        // 场景2: 链式转换（andThen / compose）
        // ═══════════════════════════════════════════════════════
        Function<String, Integer> strLen = String::length;
        Function<Integer, String> intToStr = i -> "长度: " + i;
        
        // andThen: 先执行当前，再执行参数
        Function<String, String> chain1 = strLen.andThen(intToStr);
        System.out.println(chain1.apply("Hello"));  // "长度: 5"
        
        // compose: 先执行参数，再执行当前
        Function<String, String> chain2 = intToStr.compose(strLen);
        System.out.println(chain2.apply("Hello"));  // "长度: 5"
        
        // ═══════════════════════════════════════════════════════
        // 场景3: Stream.map
        // ═══════════════════════════════════════════════════════
        List<String> names = Arrays.asList("张三", "李四", "王五");
        List<Integer> lengths = names.stream()
            .map(String::length)  // Function<String, Integer>
            .collect(Collectors.toList());
        
        // ═══════════════════════════════════════════════════════
        // 场景4: 恒等函数
        // ═══════════════════════════════════════════════════════
        Function<String, String> identity = Function.identity();
        System.out.println(identity.apply("Hello"));  // "Hello"
        
        // ═══════════════════════════════════════════════════════
        // 场景5: 基本类型特化
        // ═══════════════════════════════════════════════════════
        IntFunction<String> intToStr2 = i -> "数字: " + i;
        ToIntFunction<String> strToInt2 = s -> s.length();
        IntUnaryOperator intOp = i -> i * 2;  // int → int
        IntBinaryOperator intBinOp = (a, b) -> a + b;  // (int, int) → int
    }
}
```
* 2.6 Predicate - 断言
```
/**
 * 用途：断言，接收一个参数，返回 boolean
 * 典型场景：过滤、条件判断
 */
public class PredicateDemo {
    
    public static void main(String[] args) {
        
        // ═══════════════════════════════════════════════════════
        // 场景1: 条件判断
        // ═══════════════════════════════════════════════════════
        Predicate<Integer> isPositive = x -> x > 0;
        System.out.println(isPositive.test(5));   // true
        System.out.println(isPositive.test(-3));  // false
        
        // ═══════════════════════════════════════════════════════
        // 场景2: 逻辑组合（and / or / negate）
        // ═══════════════════════════════════════════════════════
        Predicate<Integer> isEven = x -> x % 2 == 0;
        Predicate<Integer> isGreaterThan10 = x -> x > 10;
        
        // 且：既是偶数又大于 10
        Predicate<Integer> combined1 = isEven.and(isGreaterThan10);
        System.out.println(combined1.test(12));  // true
        System.out.println(combined1.test(8));   // false
        
        // 或：是偶数或大于 10
        Predicate<Integer> combined2 = isEven.or(isGreaterThan10);
        System.out.println(combined2.test(8));   // true (是偶数)
        System.out.println(combined2.test(11));  // true (大于 10)
        
        // 非：取反
        Predicate<Integer> notPositive = isPositive.negate();
        System.out.println(notPositive.test(-3));  // true
        
        // ═══════════════════════════════════════════════════════
        // 场景3: Stream.filter
        // ═══════════════════════════════════════════════════════
        List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5, 6);
        List<Integer> evens = numbers.stream()
            .filter(x -> x % 2 == 0)  // Predicate<Integer>
            .collect(Collectors.toList());
        
        // ═══════════════════════════════════════════════════════
        // 场景4: 对象属性判断
        // ═══════════════════════════════════════════════════════
        List<User> users = Arrays.asList(
            new User("张三", 18),
            new User("李四", 25),
            new User("王五", 17)
        );
        
        Predicate<User> isAdult = u -> u.age >= 18;
        List<User> adults = users.stream()
            .filter(isAdult)
            .collect(Collectors.toList());
        
        // ═══════════════════════════════════════════════════════
        // 场景5: 基本类型特化
        // ═══════════════════════════════════════════════════════
        IntPredicate intPred = x -> x > 0;
        LongPredicate longPred = x -> x > 0L;
        DoublePredicate doublePred = x -> x > 0.0;
    }
    
    static class User {
        String name;
        int age;
        User(String name, int age) { this.name = name; this.age = age; }
    }
}
```

* 2.7 二元操作接口
```
/**
 * BiConsumer, BiFunction, BiPredicate
 * 用途：接收两个参数
 */
public class BiFunctionDemo {
    
    public static void main(String[] args) {
        
        // ═══════════════════════════════════════════════════════
        // BiConsumer: 两个参数，无返回
        // ═══════════════════════════════════════════════════════
        BiConsumer<String, Integer> printer = (name, age) -> 
            System.out.println(name + " 今年 " + age + " 岁");
        printer.accept("张三", 18);
        
        // ═══════════════════════════════════════════════════════
        // BiFunction: 两个参数，有返回
        // ═══════════════════════════════════════════════════════
        BiFunction<Integer, Integer, Integer> add = (a, b) -> a + b;
        System.out.println(add.apply(3, 5));  // 8
        
        BiFunction<String, String, Boolean> equals = String::equals;
        System.out.println(equals.apply("A", "A"));  // true
        
        // ═══════════════════════════════════════════════════════
        // BiPredicate: 两个参数，返回 boolean
        // ═══════════════════════════════════════════════════════
        BiPredicate<Integer, Integer> isGreater = (a, b) -> a > b;
        System.out.println(isGreater.test(5, 3));  // true
        
        // ═══════════════════════════════════════════════════════
        // 基本类型特化
        // ═══════════════════════════════════════════════════════
        IntBinaryOperator intAdd = (a, b) -> a + b;
        LongBinaryOperator longAdd = (a, b) -> a + b;
        DoubleBinaryOperator doubleAdd = (a, b) -> a + b;
    }
}
```

## 第3章 Lambda 表达式语法
* 3.1 基本语法
```java
// ═══════════════════════════════════════════════════════════════
// 完整语法
// ═══════════════════════════════════════════════════════════════
(参数列表) -> { 方法体 }

// ═══════════════════════════════════════════════════════════════
// 语法变体
// ═══════════════════════════════════════════════════════════════

// 1. 无参数
() -> System.out.println("Hello");

// 2. 一个参数（可省略括号）
x -> x * 2

// 3. 多个参数（必须括号）
(x, y) -> x + y

// 4. 带类型声明
(Integer x, Integer y) -> x + y

// 5. 多行方法体（需要 return）
(x, y) -> {
    int sum = x + y;
    return sum;
}

// 6. 抛出异常
(x, y) -> {
    if (y == 0) throw new ArithmeticException();
    return x / y;
}
```

* 4.1 四种方法引用类型
```java
public class MethodReferenceDemo {
    
    public static void main(String[] args) {
        
        // ═══════════════════════════════════════════════════════
        // 类型1: 静态方法引用

        Function<String, Integer> f1 = Integer::parseInt;

        IntBinaryOperator f2 = Math::max;

        String str = "Hello";

        // Lambda: (s) -> s.length()

        // Lambda: (s1, s2) -> s1.equals(s2)
```

## 第5章 函数式接口组合
* 5.1 组合方法总览
```java
// ═══════════════════════════════════════════════════════════════
// Predicate 组合
// ═══════════════════════════════════════════════════════════════
Predicate<Integer> p1 = x -> x > 0;
Predicate<Integer> p2 = x -> x < 100;

p1.and(p2);    // 且
p1.or(p2);     // 或
p1.negate();   // 非

// ═══════════════════════════════════════════════════════════════
// Function 组合
// ═══════════════════════════════════════════════════════════════
Function<Integer, Integer> f1 = x -> x + 1;
Function<Integer, Integer> f2 = x -> x * 2;

f1.andThen(f2);  // 先 f1 后 f2: (1+1)*2 = 4
f2.compose(f1);  // 先 f1 后 f2: (1+1)*2 = 4

// ═══════════════════════════════════════════════════════════════
// Consumer 组合
// ═══════════════════════════════════════════════════════════════
Consumer<String> c1 = s -> System.out.println("A: " + s);
Consumer<String> c2 = s -> System.out.println("B: " + s);

c1.andThen(c2);  // 先 c1 后 c2
```

* 8.1 常见陷阱
```java
public class PitfallsDemo {
    
    // ═══════════════════════════════════════════════════════════
    // 陷阱1: 变量捕获（必须 effectively final）
    // ═══════════════════════════════════════════════════════════
    public void trap1() {
        int count = 0;
        
        // ❌ 错误 - count 被修改
        // Runnable r = () -> System.out.println(count);
        // count++;
        
        // ✅ 正确 - 使用原子类
        AtomicInteger atomicCount = new AtomicInteger(0);
        Runnable r = () -> System.out.println(atomicCount.get());
        atomicCount.incrementAndGet();
    }
    
    // ═══════════════════════════════════════════════════════════
    // 陷阱2: 循环变量捕获
    // ═══════════════════════════════════════════════════════════
    public void trap2() {
        List<Runnable> tasks = new ArrayList<>();
        
        // ❌ 错误 - 所有任务都打印 5
        for (int i = 0; i < 5; i++) {
            tasks.add(() -> System.out.println(i));  // 编译错误
        }
        
        // ✅ 正确 - 创建 final 副本
        for (int i = 0; i < 5; i++) {
            int finalI = i;
            tasks.add(() -> System.out.println(finalI));
        }
    }
    
    // ═══════════════════════════════════════════════════════════
    // 陷阱3: 过度使用 Lambda 降低可读性
    // ═══════════════════════════════════════════════════════════
    public void trap3() {
        // ❌ 复杂 Lambda 难以理解
        list.stream()
            .filter(x -> x > 0 && x < 100 && x % 2 == 0)
            .map(x -> x * 2 + 1)
            .forEach(x -> System.out.println(x));
        
        // ✅ 提取为命名方法
        list.stream()
            .filter(this::isValidNumber)
            .map(this::transformNumber)
            .forEach(this::printNumber);
    }
    
    private boolean isValidNumber(int x) {
        return x > 0 && x < 100 && x % 2 == 0;
    }
    
    private int transformNumber(int x) {
        return x * 2 + 1;
    }
    
    private void printNumber(int x) {
        System.out.println(x);
    }
    
    // ═══════════════════════════════════════════════════════════
    // 陷阱4: 忽略异常处理
    // ═══════════════════════════════════════════════════════════
    public void trap4() {
        // ❌ 异常被吞掉
        list.forEach(item -> doSomething(item));  // 如果抛异常，难以调试
        
        // ✅ 添加异常处理
        list.forEach(item -> {
            try {
                doSomething(item);
            } catch (Exception e) {
                log.error("处理失败", e);
            }
        });
    }
}
```

* 8.3 性能注意事项
```java
public class PerformanceDemo {
    
    // ═══════════════════════════════════════════════════════════
    // 注意1: 避免不必要的装箱
    // ═══════════════════════════════════════════════════════════
    
    // ❌ 使用 Function<Integer, Integer> 会装箱
    Function<Integer, Integer> f1 = x -> x * 2;
    
    // ✅ 使用 IntUnaryOperator 避免装箱
    IntUnaryOperator f2 = x -> x * 2;
    
    // ═══════════════════════════════════════════════════════════
    // 注意2: Lambda 会创建对象
    // ═══════════════════════════════════════════════════════════
    
    // 每次调用都会创建新对象（虽然 JVM 会优化）
    public void demo() {
        for (int i = 0; i < 1000; i++) {
            // 避免在循环中创建 Lambda
            execute(() -> doWork());
        }
        
        // ✅ 提取到循环外
        Runnable task = () -> doWork();
        for (int i = 0; i < 1000; i++) {
            execute(task);
        }
    }
    
    // ═══════════════════════════════════════════════════════════
    // 注意3: 方法引用通常比 Lambda 性能更好
    // ═══════════════════════════════════════════════════════════
    
    // Lambda
    list.forEach(s -> System.out.println(s));
    
    // 方法引用（更优）
    list.forEach(System.out::println);
}
```
