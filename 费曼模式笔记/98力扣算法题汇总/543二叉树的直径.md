## 题目:二叉树的直径 (543)

- 题目描述：给定一棵二叉树，计算其直径长度。二叉树的直径是**任意两个节点路径长度中的最大值**。这条路径可能穿过也可能不穿过根节点。
- 路径长度定义：两节点之间路径的**边数**（注意：不是节点数，是边数）。

---

### 核心解法：后序遍历求深度 + 全局变量更新直径

```java
class Solution {
    int maxDiameter = 0;   // 全局记录最大直径

    public int diameterOfBinaryTree(TreeNode root) {
        depth(root);
        return maxDiameter;
    }

    // 返回以 root 为根的子树的高度（根到叶子最长路径的边数）
    int depth(TreeNode root) {
        if (root == null) return 0;   // 空节点高度为 0

        int left = depth(root.left);   // 后序遍历：先拿左右子树高度
        int right = depth(root.right);

        // 经过当前节点的路径 = 左子树高度 + 右子树高度（边数，不加 1）
        maxDiameter = Math.max(maxDiameter, left + right);

        // 当前节点的高度 = 较深的子树 + 1（连接父节点的边）
        return Math.max(left, right) + 1;
    }
}
```

**思路分析：**

核心洞察：**任意一条路径都有一个"最高点"**（路径上最靠近根的那个节点）。如果我们能算出"每个节点作为最高点时，经过它的最长路径"，那么全局最大值就是答案。

而"经过某节点的最长路径" = **左子树高度 + 右子树高度**（从该节点向左最长走下去的边数 + 向右最长走下去的边数）。

所以边**后序遍历**边做两件事：
1. 返回子树高度（供父节点使用）
2. 用 `左高 + 右高` 尝试更新全局直径

**关键：`+1` 到底在哪加？**

这是最容易错的地方，记住一句口诀：
> **更新直径不加 1，返回高度才加 1**

- `maxDiameter = max(maxDiameter, left + right)` —— 路径是"左子树走下来的边 + 右子树走下来的边"，**根节点本身不是边，不加 1**
- `return max(left, right) + 1` —— 返回的是"高度"（该节点到其子树最深叶子的边数），要**加上自己到子树的这条边，所以 +1**

**为什么可以"可能不穿过根节点"？**

后序遍历会在**每一个节点**都尝试更新 `maxDiameter`，所以即使最长路径在某个内部节点（不在根节点上）分叉，也会在递归到该节点时被记录到，跟根无关。

**复杂度：**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，递归栈深度，最坏 O(n)

### 犯错记录 / 面试注意点

1. **直径是边数不是节点数**：例：单节点树直径 = 0（没有边）。如果题目按"节点数"算，答案要 +1，务必看清题意。
2. **`+1` 位置**：更新直径用 `left + right`（不加），返回高度用 `Math.max(left,right)+1`（加）。混淆会导致结果差 1。
3. **全局变量 vs 返回值**：直径用成员变量 `maxDiameter` 维护（因为路径可能横跨左右子树，无法用单一返回值表达）；递归函数返回值只表达"高度"。
4. **与 104 最大深度的关系**：104 只返回高度；543 在返回高度的基础上**额外用左右高度和更新全局答案**。理解 104 是理解 543 的前提。
