## 题目：对称二叉树

- 题目描述：给你一个二叉树的根节点 `root`，检查它是否轴对称。

---

### 解法A：递归法（自顶向下镜像比较）

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        return check(root.left, root.right);
    }

    boolean check(TreeNode p, TreeNode q) {
        if (p == null && q == null) return true;
        if (p == null || q == null) return false;
        if (p.val != q.val) return false;
        return check(p.left, q.right) && check(p.right, q.left);
    }
}
```

**思路分析：**

镜像对称比较的是两个子树对应位置的节点，而不是同一个子树的前序/后序遍历。

对称比较的逻辑：
- 左子树的**左**孩子 vs 右子树的**右**孩子（镜像对①）
- 左子树的**右**孩子 vs 右子树的**左**孩子（镜像对②）
- 两个镜像对都对称 → 整棵树对称

**逐层排除的代码风格：**

这个写法的核心是理解「if-return 链」而不是「if-else 分支」：

```
① if (p == null && q == null) → 都空，直接对称 ✅，return
② if (p == null || q == null) → 一个空，结构不对称 ❌（走到这步说明①不满足）
③ if (p.val != q.val) → 值不同 ❌（走到这步说明①②都不满足）
④ 走到这 → 两个都不空 && 值相等 → 放心递归两个镜像对
```

**关键技巧：** 后面的分支隐含了前面所有条件都失败的语义，不需要再写 else 或者多余的条件判断。

**复杂度：**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，递归深度

### 解法B：迭代法（队列成对入队）

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        Deque<TreeNode> queue = new LinkedList<>();
        queue.offer(root.left);
        queue.offer(root.right);

        while (!queue.isEmpty()) {
            TreeNode p = queue.poll();
            TreeNode q = queue.poll();

            if (p == null && q == null) continue;
            if (p == null || q == null) return false;
            if (p.val != q.val) return false;

            // 成对入队：镜像位置绑在一起
            queue.offer(p.left);
            queue.offer(q.right);
            queue.offer(p.right);
            queue.offer(q.left);
        }
        return true;
    }
}
```

**思路分析：**

把递归改显式的队列，本质没变，只是用自己的队列代替了系统栈。

关键设计是**成对入队**：
- 每次取两个节点出来比较
- 如果对称，把它们的子节点按镜像对入队
- 队列为空说明所有镜像对都通过了验证

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，队列长度

---

### 递归 vs 迭代

| 维度 | 递归法 | 迭代法 |
|------|--------|--------|
| 代码量 | 6行，简洁 | 14行，略长 |
| 理解难度 | 直观 | 稍绕（需理解成对入队） |
| 面试偏好 | 推荐，简洁清晰 | 可提及，展示多解法 |
| 适用场景 | 树的深度可控 | 树深度可能很大的情况（防栈溢出） |

### 解法对比：验证二叉搜索树 vs 对称二叉树

```
验证二叉搜索树（98题）          对称二叉树（101题）
   范围递归 / 中序升序         镜像成对比较
   约束向下传                  对应点匹配
   左子树全体 < root            左子左 ↔ 右子右
   右子树全体 > root            左子右 ↔ 右子左
```

两题思路的共同点：**定位一棵树的不同部分，建立对应关系，递归验证**。区别只是 98 是数值约束的传递，101 是位置镜像的匹配。

### 写递归的心法：「三问法」

写不出递归时，不要急着敲代码，先问三个问题：

**① 这个递归函数是干什么的？签名定死。**
```
check(TreeNode p, TreeNode q) → 判断 p 和 q 这两棵子树是不是镜像对称
```

**② 哪些情况可以直接下结论？（base case）**
- 两个空 → 对称 ✓
- 一个空 → 不对称 ✓
- 值不同 → 不对称 ✓

**③ 不能直接下结论时，怎么拆成子问题？**
```
p 和 q 对称 ↔ p.left 和 q.right 对称 && p.right 和 q.left 对称
```

把三问答案写注释 → 翻译成代码 → 收工。

### 犯错记录

1. **空指针来源**：先访问了子节点的属性（`.val` / `.left` / `.right`），再判断节点本身是否为 null。正确的顺序是先判 null，再访问。

2. **if-else 链陷阱**：试图枚举所有可能性，结果条件覆盖不全导致漏判。正确的做法是「逐层排除」：把所有能直接下结论的 case 用 if-return 排掉，剩下的自然就是安全的。

3. **混淆前序/后序遍历与对称比较**：最初以为"左子树前序 + 右子树后序遍历结果一致就是对称"，实际对称比较是对镜像位置的节点一一比较，而非按遍历顺序比。
