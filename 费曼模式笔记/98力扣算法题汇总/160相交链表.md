## 相交链表
* 给你两个单链表的头节点 headA 和 headB ，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 null 。
* java 实现
    ```java
        /**
         * Definition for singly-linked list.
        * public class ListNode {
        *     int val;
        *     ListNode next;
        *     ListNode(int x) {
        *         val = x;
        *         next = null;
        *     }
        * }
        */
        public class Solution {
            public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
                ListNode headAregisit = headA;
                ListNode headBregist = headB;
                //边界处理如果传入的headA或者headB是null的话
                if(headA==null || headB ==null){return null;}

                while(headA != headB){
                    headA = (headA == null)?headBregist:headA.next;

                    headB = (headB ==null)?headAregisit:headB.next;
                }

                return headA;
            }
        }
    ```

* 核心思路点 **双指针换位法** :
    设置两个指针分别从各自的头节点出发，以此.next遍历，当next为空的时候就去遍历另外一个链表 比如链表A遍历完成后去遍历链表B。 循环的设置条件为 `headA != headB` :
    好处，情况1 假如两个链表没有交点，当遍历次数达到 headA.length 和 headB.length 时候，两个结点均为null这时候退出循环，且返回值正确。
    情况2有交点，逆向思考首先尾巴节点肯定是一样的，往回遍历到初次相遇的节点的时候，就得到了正确的结果，这时候也会跳出循环返回的值也是正确的。
