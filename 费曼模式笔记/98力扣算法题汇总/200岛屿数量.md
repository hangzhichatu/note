# 200. 岛屿数量（Medium）

- 题目描述：给你一个由 '1'（陆地）和 '0'（水）组成的二维网格，计算岛屿的数量。一个岛被水包围，并且它是通过水平方向或垂直方向上相邻的陆地连接而成。

---

### 解法：DFS 沉没法（标准最优解）

```java
class Solution {
    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) {
            return 0;
        }
        int count = 0;
        int rows = grid.length;
        int cols = grid[0].length;

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] == '1') {
                    count++;           // 发现新岛屿
                    dfs(grid, i, j);   // 沉没整个岛屿
                }
            }
        }
        return count;
    }

    // 把相连的陆地 '1' 全部改成 '0'（沉没/标记已访问）
    public void dfs(char[][] grid, int row, int col) {
        // 越界 或 已访问(水'0') 直接返回
        if (row < 0 || row >= grid.length || col < 0 || col >= grid[0].length
            || grid[row][col] == '0') {
            return;
        }
        grid[row][col] = '0';  // 沉没当前格子
        // 四方向遍历
        dfs(grid, row + 1, col);
        dfs(grid, row - 1, col);
        dfs(grid, row, col + 1);
        dfs(grid, row, col - 1);
    }
}
```

**思路分析：**

核心思想是"扫到陆地就沉没整个岛"，避免重复计数：

```
① 双层循环扫描网格
   - 遇到 '1'（未被访问的陆地）→ 说明发现了一个新岛屿 → count++
   - 给这个岛屿做 DFS，把它相连的所有 '1' 改成 '0'（沉没）
② 内层循环继续扫
   - 已经被沉没的格子是 '0'，不会再触发计数 → 保证每个岛只计一次
```

**为什么沉没成 '0' 而不是用 visited 数组？**

`'0'`（水）和 visited 标记本质一样——表示"这个格子要么没陆地，要么已经处理过"。直接改原数组省空间，但**会修改输入**；面试提一句"如果不想改原数组，可用 visited 数组"即可。

### ⚠️ 手撕 Bug（重要教训）

**命名不一致导致编译错误！**

```java
// ❌ 错误示范（Boss 第一次提交）
public void dfs(char[][] grid, int row, int cow) {   // 参数叫 cow
    if (... || grid[row][col] == '0') {              // 使用处写 col —— col 未声明！
        return;
    }
    grid[row][cow] = '0';                            // 又用回 cow
    dfs(grid, row + 1, cow);
    ...
}
```

参数叫 `cow`，使用处却写 `col` → **`col` 未定义，编译报错**。

**教训（面试手撕最冤的扣分点）：**
1. **传参和使用的变量名必须一眼能对上**（命名统一、语义清晰）
2. 手撕完**自查一遍所有引用的变量**是否都已声明
3. `col` 是 column 缩写，语义清楚，优先用；`cow` 拼写怪且易错

**思路是对的，栽在拼写上最不值。** 这类低级错误现在犯，面试就不犯。

### 复杂度
- 时间 O(rows × cols)，每个格子至多访问一次
- 空间 O(rows × cols) 最坏（递归栈深度，全陆地时）

---

### 同类题对比 / 延伸

| 做法 | 特点 |
|------|------|
| **DFS 沉没法** | 递归，空间 O(h)，最直观（本题解法）|
| **BFS** | 队列，迭代，适合避免深递归栈溢出 |
| **并查集 Union-Find** | O(α(n)) 近常数，面试加分项；统计连通分量数 |

**面试常追问：** 除了 DFS，这题还能怎么做？
- **BFS**：遇到 '1' 用队列做层序扩散，同样沉没
- **并查集**：每个 '1' 与上下左右相邻的 '1' union，最后统计有多少个独立集合（根节点数）
