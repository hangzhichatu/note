# 226. 翻转二叉树（Easy）

- 题目描述：翻转一棵二叉树，即交换每个节点的左右子节点。

---

### 解法一：递归（标准解）

```java
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null;
        // 暂存左右，再交换
        TreeNode left = root.left;
        TreeNode right = root.right;
        root.left = right;
        root.right = left;
        invertTree(left);   // 翻转原左子树（现在在右侧）
        invertTree(right);  // 翻转原右子树（现在在左侧）
        return root;
    }
}
```

**思路分析：**
核心思想：**父子节点的相对顺序不变，变的是左右/兄弟节点位置** —— 本质是"交换每个节点的左右孩子，再递归处理子树"。

**为什么交换要暂存变量？**
- 引用赋值是**覆盖式**的：`root.right = root.left` 会**覆盖掉 `root.right` 的原值**
- 所以要先暂存至少一个（标准写法暂存 left；Boss 写法左右都暂存，更安全）
- 面试话术："交换两个引用必须暂存其中一个，否则第一个赋值就会覆盖另一个引用的原值"

> ⚠️ 易错点：被覆盖的是**左值** `root.right`（不是 root.left）。`root.right = root.left` 把原右子树冲掉了，原左子树仍在 root.left。

### 解法二：递归（更简洁，边交换边递归）
```java
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode tmp = root.left;
    root.left = invertTree(root.right);  // 原右子树翻好转给左
    root.right = invertTree(tmp);        // 原左子树翻好转给右
    return root;
}
```
两种等价，面试随缘选。

---

### 复杂度
- 时间 O(n)，每个节点访问一次
- 空间 O(h) 递归栈深度

---

### 同类题延伸
- **迭代法**：用栈/队列 BFS，每个节点弹出来就交换左右，再入队，O(n)
- **对称二叉树（101）**：判断一棵树是否镜像对称，是本题的姊妹题
