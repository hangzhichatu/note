## 反转链表与回文链表


* 反转链表是链表操作的重要基础操作，时间复杂度n 空间复杂度 1 这个给出参考的反转链表操作代码，需要背诵记忆

```java
 /**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public boolean isPalindrome(ListNode head) {
        //返回标识符默认为true
        boolean returnFlag = true;
        //使用快慢指针
        ListNode fast = head;
        ListNode slow = head;
        //先找中间
        while(fast !=null && fast.next != null && fast.next.next !=null){
            slow = slow.next;
            fast = fast.next.next;
        }

        //分情况讨论，如果单链表长度是偶数数的话，那么slow停止的位置就是n/2的位置是奇数的话停止的位置是 n/2下取整
        //所以把 slow.next到结尾部分链表反转，双指针判断是否相等 （slow 指针的next开始，停止条件是当头指针到slow.next了）
        ListNode half = reverseList(slow.next);

        while(head !=null && half !=null){
            if(head.val != half.val){
                returnFlag = false;
            }
            head = head.next;
            half = half.next;
        }



        return returnFlag;
    }

    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        return prev;
    }
}

```

* 这里reverseList就是反转链表的操作，它申请了两个辅助遍历 prev和curr用来记录前驱和当前处理节点，这里有个需要注意的点是 `ListNode next= curr.next` ,这个变量每次都需要新声明不要尝试提前声明一个变量来每次操作时候赋值，这样会导致链表断裂的。


* 回文链表就是在反转链表操作基础上，首先利用快慢指针找到中间节点，然后反转后半部分链表，然后对比。 改方法实际复杂度是 1空间复杂度是 n，算是最优的空间时间方法了。
