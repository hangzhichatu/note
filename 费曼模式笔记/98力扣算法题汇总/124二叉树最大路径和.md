## 124. 二叉树中的最大路径和（Hard）

- 题目描述：二叉树中，路径被定义为一条从任意节点出发，沿父/子连接到达另一任意节点的**一条线**（不分叉）。路径和是路径上节点值的总和。返回最大路径和。

---

### 解法：分治递归

```java
class Solution {
    int maxSum = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        maxGain(root);
        return maxSum;
    }

    // 返回：以 node 为起点的最大「单向」贡献值（只能走一边，不能分叉）
    public int maxGain(TreeNode node) {
        if (node == null) return 0;

        // 左右子树的贡献，负数就不拿（当不存在）
        int leftGain = Math.max(0, maxGain(node.left));
        int rightGain = Math.max(0, maxGain(node.right));

        // 当前节点作「拐点」的路径和 = 左贡献 + 自己 + 右贡献
        int curPathSum = leftGain + node.val + rightGain;
        maxSum = Math.max(maxSum, curPathSum);

        // 返回给父节点：只能选一边往上走
        return node.val + Math.max(leftGain, rightGain);
    }
}
```

**思路分析：**

核心思想是从底向上计算每个节点的两种角色：

```
① 拐点角色：路径在 node 这里拐弯（左 + 自己 + 右）
   → 更新全局最大值，路径到此为止，不再往上送

② 单向通道角色：路径穿过 node 继续往上走
   → 只能选左或右一边，返回 node.val + max(左贡献, 右贡献)
```

**为什么返回时只能选一边？**

路径不能分叉。如果 node 同时拿了左右两侧，路径就变成了一个"Y"字形。从下往上走的过程中，每个节点只能选择**一条路**。

两边都走的场景并没有丢失——它在拐点角色的计算中被记录了。

```
       父节点
          |
       ┌──●──┐          ← node 只能把一边往上送
       │      │           另一边已经在 curPathSum 里记录过了
    左子树   右子树
```

**为什么取 Math.max(0, gain)？**

负数的子树贡献，加上去反而让总和变小。`Math.max(0, gain)` 表示"如果这个子树是负收益，那就别走它"，等效于不存在。

---

### 分步走一遍示例

```
    -10
    / \
   9   20
       / \
      15  7
```

| 节点 | leftGain | rightGain | curPathSum | maxSum | 返回值 |
|------|----------|-----------|------------|--------|--------|
| 15 | 0 | 0 | 15 | 15 | 15 |
| 7 | 0 | 0 | 7 | 15 | 7 |
| 20 | 15 | 7 | **42** ← 拐点记录 | **42** | 20+max(15,7)=**35** |
| 9 | 0 | 0 | 9 | 42 | 9 |
| -10 | 9 | 35 | 34 | 42 | -10+35=25 |

最大路径 42 = `15 → 20 → 7`，在节点 20 处作为拐点记录。根节点 -10 参与了但没超过。

---

### 常见 Bug

1. **初始值设 0：** 如果所有节点都是负数，最大路径和应该是最大的那个负数（不走才是 0），`maxSum = 0` 会得到 0 而不是正确答案。必须用 `Integer.MIN_VALUE`。

2. **递归循环调用：** 在 `maxGain` 里调 `maxPathSum`（或反过来），导致死循环/栈溢出。正确做法是统一的单向递归。

3. **两边都返回：** 直接返回 `leftGain + node.val + rightGain` 给父节点，导致父节点再往上接时路径分叉成三岔。

4. **负数不处理：** 认为"负数就不该走这条路径所以 return 0"。正确做法是 `Math.max(0, gain)` 在父节点做选择，而不是在子节点截断。

---

### 复杂度

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，h 为树高

### 同类题对比

| 题目 | 核心思想 | 返回值含义 |
|------|---------|-----------|
| 104 最大深度 | 子问题分解：1 + max(左, 右) | 子树的高度 |
| 124 最大路径和 | 分角色：拐点记录全局，单向贡献返回 | 子树的最大单向贡献 |

124 是 104 的升级版：104 只数层数不需要考虑正负分叉，124 需要同时处理负数截断和路径不分叉的约束。
