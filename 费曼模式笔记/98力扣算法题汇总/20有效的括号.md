# 20. 有效的括号（Easy）

- 题目描述：给定一个只包括 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断字符串是否有效。有效字符串需满足：① 左括号必须用相同类型的右括号闭合；② 左括号必须以正确的顺序闭合；③ 每个右括号都有一个对应的相同类型的左括号。

---

### 核心解法：栈匹配（O(n) / O(n)）

```java
class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            // 技巧：遇到左括号，把"对应的右括号"压栈
            // 这样后续只要比对 pop 出来的字符 == 当前字符 即可，无需再判断类型
            if (c == '(') stack.push(')');
            else if (c == '{') stack.push('}');
            else if (c == '[') stack.push(']');
            else {
                // 关键：遇到右括号时，栈为空或栈顶不匹配，直接返回 false
                if (stack.isEmpty() || stack.pop() != c) {
                    return false;
                }
            }
        }
        return stack.isEmpty(); // 遍历完栈必须为空（不能有未闭合的左括号）
    }
}
```

**思路分析：**

栈天然适合"括号匹配"——遇到左括号就压栈（等待对应右括号），遇到右括号就弹出栈顶比对：

```
① 遍历字符串
   - 左括号 '(' '{' '[' → 压栈 【压的是对应右括号，见下方技巧】
   - 右括号 → 弹出栈顶比对
② 匹配失败返回 false 的两种情况：
   - 栈为空却遇到右括号（形如 "]()" —— 右括号多余）
   - 栈顶与其不匹配（形如 "(]" —— 类型不对）
③ 全部遍历完 → 栈必须为空（形如 "(()" —— 左括号多了没闭合）
```

⚠️ 判断 `isValid` 用 `EnumSet`？—— 不需要，本题就三种括号，`if/else` 足够清晰。

---

### 💡 关键技巧：压入"对应的右括号"而非左括号

> 这是本解法最巧妙的一点（也是**面试加分点**）。

**常规写法**：压入左括号，遇到右括号时再用一个 map/switch 判断"栈顶的左括号"是否与"当前右括号"配对：

```java
if (c == '(') stack.push(c);
else if (c == ')') stack.pop() != '(' -> false  // 还要判断类型
// 每种右括号都要写一遍配对判断，啰嗦
```

**优化写法（本题采用）**：压栈时**直接压入它该配对的右括号**。这样遇到右括号时，只需要判断 `stack.pop() == c` 一个条件，**类型判断被"预映射"掉了**——左括号 → 右括号的对应关系在入栈那一刻就定好了。

```
'(' → 压 ')'    '{' → 压 '}'    '[' → 压 ']'
遇到 ')'：stack.pop() 应该是 ')'，等于就匹配
```

**好处**：代码更短、分支更少、不易写错配对关系。面试可以主动点出这个优化，体现代码洁癖。

---

### ⚠️ 手撕注意点 / 易错点

1. **用 `Deque` 而不是 `Stack` 类**：Java 官方已建议用 `ArrayDeque` 实现栈（`push`/`pop`/`peek`），`java.util.Stack` 继承 `Vector` 有线程同步开销，且性能差。面试主动说"用 Deque、avoid Stack"是加分细节。

2. **漏掉"栈为空"的判断会导致 NPE/错判**：
   ```java
   // ❌ 错：遇到右括号直接 pop，可能从空栈 pop 抛异常，且漏掉了"右括号多余"的场景
   else if (stack.pop() != c) return false;
   // ✅ 对：先判空，再 pop 比较（"快速失败"，条件写在最前）
   else { if (stack.isEmpty() || stack.pop() != c) return false; }
   ```
   注意 `stack.isEmpty() || stack.pop() != c` **顺序不能反**：`||` 短路，`isEmpty()` 为 true 时不会执行 `pop()`，从而避免空栈报错。这是"短路求值"的妙用。

3. **最后必须返回 `stack.isEmpty()`**，不能 `return true`：否则 `"(()"`（左括号未闭合）会被误判为合法。这是最常见的遗漏点。

4. **字符比较用 `!=`（基础类型 char）**：`c` 是 `char`（基础类型），直接 `stack.pop() != c` 即可，不需要 `.equals()`。容易和 `Integer`/`String` 混淆，但 char 没有这个问题。

**面试常追问**：能不能只用一个 `int` 计数器代替栈（遇到 `(` 加 1，遇到 `)` 减 1 最后看是否为 0）？
- **不能**。计数器只统计左右括号数量相等，**无法处理类型不匹配**（如 `"(]"`）和**顺序错乱**（如 `")("`）——这两种都能让计数器最后归零却非法。栈的核心价值正是保留了"最近未匹配的左括号"这一**顺序信息**。
