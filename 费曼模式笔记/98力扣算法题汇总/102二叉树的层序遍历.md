## 二叉树的层序遍历
* 题目描述
      * 给你二叉树的根节点 root ，返回其节点值的 层序遍历 。 （即逐层地，从左到右访问所有节点）。
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
```

* 思路解析：算法基础，广度优先遍历，使用辅助 **队列变量**（先进先出，且能够很好的定义每个层级的要访问处理的节点，只要队列空了则说明循环条件可以停止了）改思路算法时间复杂度是 n空间复杂度需要一个 大小和n相关的辅助队列

**代码实现**
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        //思路 1 广度优先遍历 使用中间辅助 队列，先入列后出列，当列为空时返回 思路
        List<List<Integer>> result = new ArrayList<>();
        if(root == null){
            return result;
        }
        Queue<TreeNode> queue = new LinkedList<>();//辅助队列
        queue.offer(root); // 将根节点入队

        while(!queue.isEmpty()){
            int levelSize = queue.size();//确定下当前层级的节点数目
            // 临时列表，用来存放当前这一层的所有节点值
            List<Integer> currentLevelList = new ArrayList<>();
        

            // 遍历当前层的所有节点
            for (int i = 0; i < levelSize; i++) {
                // 出队一个节点
                TreeNode currentNode = queue.poll();

                // 将该节点的值加入当前层列表
                currentLevelList.add(currentNode.val);

                // 如果左子节点存在，将其入队（作为下一层的节点）
                if (currentNode.left != null) {
                    queue.offer(currentNode.left);
                }

                // 如果右子节点存在，将其入队（作为下一层的节点）
                if (currentNode.right != null) {
                    queue.offer(currentNode.right);
                }

               
            }
             //当前层级结束将该层的列表加入最终结果集
            result.add(currentLevelList);
            
    }
    return result;
    }
    
}
```
