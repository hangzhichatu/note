## 104. 二叉树的最大深度

- 题目描述：给定二叉树根节点，返回最大深度（根到最远叶子节点的节点数）。

---

### 解法：递归（DFS）

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
    }
}
```

**思路分析：**

子问题分解法：一棵树的最大深度 = 1（当前层） + Max(左子树最大深度, 右子树最大深度)

递归基：空节点深度为 0。

**空指针来源：** 递归调用 `root.left` / `root.right` 之前已经判了 null，安全。

**复杂度：**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，h 为树高，最坏 O(n)（链表型树）

---

### 解法B：层序遍历（BFS）

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int depth = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            depth++;
        }
        return depth;
    }
}
```

**思路分析：**

按层遍历，每处理完一层 depth++，最终层数 = 深度。

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，队列最大宽度

---

### 递归 vs 迭代

| 维度 | 递归 (DFS) | 迭代 (BFS) |
|------|-----------|-----------|
| 代码量 | 3行 | 10行 |
| 理解难度 | 直观 | 稍长 |
| 面试偏好 | 推荐，最简 | BFS写法也常见 |
| 适用场景 | 通用 | 树宽不大时可用 |

## 105. 从前序与中序遍历序列构造二叉树

- 题目描述：给定前序 preorder 和中序 inorder，重建二叉树。

---

### 解法 A：分治递归（数组拷贝版）

```java
class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        if (preorder.length == 0) return null;

        // 1. 前序第一个 = 根
        int rootVal = preorder[0];

        // 2. 中序中找根的位置
        int rootIndex = 0;
        for (int i = 0; i < inorder.length; i++) {
            if (inorder[i] == rootVal) {
                rootIndex = i;
                break;
            }
        }

        // 3. 左子树大小 = rootIndex
        int leftSize = rootIndex;

        // 4. 切分左右子树的前序和中序
        int[] leftPreorder = Arrays.copyOfRange(preorder, 1, 1 + leftSize);
        int[] leftInorder   = Arrays.copyOfRange(inorder, 0, rootIndex);

        int[] rightPreorder = Arrays.copyOfRange(preorder, 1 + leftSize, preorder.length);
        int[] rightInorder   = Arrays.copyOfRange(inorder, rootIndex + 1, inorder.length);

        // 5. 递归构建
        TreeNode node = new TreeNode(rootVal,
                buildTree(leftPreorder, leftInorder),
                buildTree(rightPreorder, rightInorder));
        return node;
    }
}
```

**思路分析：**

核心逻辑：**前序定根，中序分左右。**

```
前序： [3,  9,  20,15,7]
中序： [9,  3,  15,20,7]
         ↑
      根=3，中序位置=1
      
左子树前序 = preorder[1] 起取 1 个 = [9]
左子树中序 = inorder[0] 到根前 = [9]

右子树前序 = preorder[1+1] 到末尾 = [20,15,7]
右子树中序 = inorder[根+1] 到末尾 = [15,20,7]
```

**关键点：** 左子树大小 = rootIndex（中序里根左边的元素个数），前序通过左子树大小来切分左右。

**复杂度：**
- 时间复杂度：O(n²)，每层递归要找根在中序的位置（遍历 n 次）
- 空间复杂度：O(n²)，每次拷贝数组

---

### 解法 B：优化版 — 指针 + 哈希表（推荐）

```java
class Solution {
    Map<Integer, Integer> map = new HashMap<>();
    int preIndex = 0;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        // 哈希表存中序 {值 → 位置}，O(1) 找根位置
        for (int i = 0; i < inorder.length; i++) {
            map.put(inorder[i], i);
        }
        return build(preorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] preorder, int left, int right) {
        if (left > right) return null;

        int rootVal = preorder[preIndex++];
        int rootIndex = map.get(rootVal);

        TreeNode node = new TreeNode(rootVal);
        node.left = build(preorder, left, rootIndex - 1);
        node.right = build(preorder, rootIndex + 1, right);

        return node;
    }
}
```

**思路分析：**

免去了每次递归创建新数组的开销：
- `preIndex` 指针顺序扫前序数组，保证每次拿到的就是当前子树的根
- `left/right` 指针划定当前子树在中序中的范围
- 哈希表 O(1) 找到根在中序的位置

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)（哈希表 + 递归深度）

---

### 解法对比

| 维度 | 数组拷贝版 | 指针+哈希表 |
|------|-----------|-----------|
| 时间复杂度 | O(n²) | O(n) |
| 空间复杂度 | O(n²) | O(n) |
| 理解难度 | 直观 | 稍绕（指针移动） |
| 代码量 | 短 | 略长 |
| 面试推荐 | 优先写这个讲思路 | 优化方向提即可 |

---

### 常见错误

1. **数组边界算错：** 左子树前序是 `preorder[1] ~ preorder[leftSize]`，也就是 `copyOfRange(preorder, 1, 1 + leftSize)`。容易写成 `copyOfRange(preorder, 1, leftSize)`。

2. **中序根位置算错：** 中序数组里根的左边元素个数 = rootIndex（0-based），右边元素个数 = len - rootIndex - 1。

3. **递归基写错：** 不是 `preorder.length == 0` 就完了——优化版里递归基是 `left > right`。
