## 题目:接雨水 (42)

- 题目描述：给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。
- 关键理解：**某格能存的水 = min(该格左侧最高墙, 该格右侧最高墙) - 该格高度**（结果为正才累积）。

---

### 核心解法：双指针（O(n) / O(1)）

```java
class Solution {
    public int trap(int[] height) {
        int n = height.length;
        if (n <= 2) return 0;

        int left = 0, right = n - 1;
        int leftMax = 0, rightMax = 0;   // 记录左右两侧已见过的最高墙
        int ans = 0;

        while (left < right) {
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);

            if (leftMax <= rightMax) {
                // 左侧高度矮：右侧有更高的墙兜底，水位由 leftMax 决定
                ans += leftMax - height[left];
                left++;
            } else {
                ans += rightMax - height[right];
                right--;
            }
        }
        return ans;
    }
}
```

**思路分析（为什么哪边矮就处理哪边）：**

每格能存的水 = `min(左Max, 右Max) - height[i]`。双指针从两端向内：
- 维护 `leftMax`（left 及其左边见过的最高墙）、`rightMax`（right 及其右边见过的最高墙）
- 当 `leftMax <= rightMax`：说明**右侧一定有墙能兜住 leftMax**，所以 left 位置的水位**确定 = leftMax**，直接算 `leftMax - height[left]`，安全；反之对称
- **"矮侧优先"保证该侧水位已由更高那侧兜底，不会算错**——这是 vs 朴素解法的核心

**复杂度：** O(n) 一次遍历；O(1) 额外空间。

---

### 🐛 犯过错：直接用"单侧高度当水位"，缺 min 边界（多算水）

**错误版核心逻辑：**
```java
if (height[left] < height[right]) {
    // 直接拿 height[left] 当水位，向右累计 (height[left]-height[i])
} else {
    // 拿 height[right] 当水位，向左累计
}
```

**为什么错：** 它**没有用 "min(左最高, 右最高)" 来确定水位，而是直接用当前那一侧的高度当水位**。当两侧等高、或有多个波峰波谷时，会**多算水**（把本不该有水的位置算进去了）。

**反例（错误版返回 8，正确应是 6）：**
```
height = [3, 1, 2, 0, 2, 1, 3]  →  正确 6；错误版多算成 8
```

**教训：** 双指针接雨水不是"单侧向另一侧累计差值"，而是**每格独立用" min(两侧历史最高) - 当前高度 "**。核心是维护 `leftMax / rightMax` 两个**历史最高**变量，而不是移动指针时临时比较相邻值。

### 其他解法速览（面试可提）

| 解法 | 时间复杂度/空间 | 说明 |
|------|:---:|------|
| 暴力 | O(n²)/O(1) | 每格向左向右找最高墙 |
| 前缀最值 | O(n)/O(n) | 预计算 leftMax[i]/rightMax[i] 数组 |
| 双指针 | O(n)/O(1) | ⭐ 最优，左右向内收敛 |
| 单调栈 | O(n)/O(n) | 按行/按列处理的水位，适用于变体 |

---

### 面试注意点

1. **先说思路再写**：主动讲"每格水量 = min(左右最高) - 高度"，比直接抛双指针更显功底
2. **边界**：`n <= 2` 直接返回 0（至少 3 根柱子才可能存水）
3. **双指针的矮侧优先**：为什么处理矮侧安全——因为高侧已经兜底确定水位
