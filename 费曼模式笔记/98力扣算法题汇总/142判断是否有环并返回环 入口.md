## 判断是否有环并且返回环入口节点

```java
    /**
     * Definition for singly-linked list.
     * class ListNode {
     *     int val;
     *     ListNode next;
     *     ListNode(int x) {
     *         val = x;
     *         next = null;
     *     }
     * }
     */
    public class Solution {
        public ListNode detectCycle(ListNode head) {
            // 1. 边界检查
            if (head == null || head.next == null) {
                return null;
            }

            ListNode slow = head;
            ListNode fast = head;

            // 2. 第一步：判断是否有环
            while (fast != null && fast.next != null) {
                slow = slow.next;       // 走 1 步
                fast = fast.next.next;  // 走 2 步

                // 如果相遇，说明有环
                if (slow == fast) {
                    // 3. 第二步：寻找环的入口
                    // 定义一个新指针从头出发
                    ListNode ptr = head;
                    // 两个指针同步走，每次 1 步
                    while (ptr != slow) {
                        ptr = ptr.next;
                        slow = slow.next;
                    }
                    // 再次相遇点即为入口
                    return ptr;
                }
            }

            // 如果循环结束还没相遇，说明无环
            return null;
        }
    }
```

* 141 基础上如何寻找相遇点理论推导说明

```txt
    假设：
    a：从头节点到环入口的距离。
    b：从环入口到相遇点的距离。
    c：从相遇点回到环入口的距离（环的剩余部分）。
    那么，环的总长度 = b + c。
    推导过程：
    当快慢指针相遇时：
    慢指针 (slow) 走过的路程是：a + b
    快指针 (fast) 走过的路程是：a + b + n * (b + c) （n 是快指针在环内多绕的圈数）
    因为快指针的速度是慢指针的 2 倍，所以路程也是 2 倍：
    2 * (a + b) = a + b + n * (b + c)
    化简这个等式：
    a + b = n * (b + c)
    a = n * (b + c) - b
    a = (n - 1) * (b + c) + c  (解读关键点)

    从第三个指针出发 ，现在 慢指针移动 举离入口 为b 那么在走距离a，或者说 (n-1)圈的环的长度加 C即可回到入口，这时候 如果有一个指针从头同时和慢指针行动的话两个指针可以在入口相遇。
```
