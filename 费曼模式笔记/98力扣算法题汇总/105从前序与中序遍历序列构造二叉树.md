## 从前序与中序序列构造二叉树
* 核心思路如下首先从前序序列的首位就是当前子树的根节点， 假设这个节点在中序序列里面的位置是n 那么就说明 其左子树右 n-1个节点，右子树右 length - n 个节点
* 其中前序序列 下标 1到n的位置 是左子树的前序序列， n+1到 length是右子树的中序序列
* 优化思路，实际上因为对中序序列和前序序列并没做更删改的操作，所以通过移动下标来实现切分左右子树比声明一个新的对象要好得多
* 边界条件判断当当前 前序序列或者中序序列 的边界不合法就说明到空节点了需要return


```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    // 使用成员变量，避免在递归中反复传参
    private Map<Integer, Integer> indexMap;
    private int[] preorder;
    private int[] inorder;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        this.preorder = preorder;
        this.inorder = inorder;
        
        // 预处理：将中序遍历的值和下标存入哈希表，实现 O(1) 查找
        indexMap = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) {
            indexMap.put(inorder[i], i);
        }
        
        // 启动递归，传入整个数组的边界下标 [0, length - 1]
        return build(0, preorder.length - 1, 0, inorder.length - 1);
    }

    /**
     * 递归构建树
     * @param preL 当前子树在前序遍历中的左边界
     * @param preR 当前子树在前序遍历中的右边界
     * @param inL  当前子树在中序遍历中的左边界
     * @param inR  当前子树在中序遍历中的右边界
     */
    private TreeNode build(int preL, int preR, int inL, int inR) {
        // 递归终止条件：如果边界不合法（左边界大于右边界），说明当前子树为空
        if (preL > preR || inL > inR) {
            return null;
        }

        // 1. 前序遍历的第一个元素就是当前子树的根节点
        int rootVal = preorder[preL];
        TreeNode root = new TreeNode(rootVal);

        // 2. 在中序遍历中找到根节点的位置
        int rootIndex = indexMap.get(rootVal);

        // 3. 计算左子树的节点个数
        int leftSize = rootIndex - inL;

        // 4. 递归构建左子树
        // 前序左子树范围：[preL + 1, preL + leftSize]
        // 中序左子树范围：[inL, rootIndex - 1]
        root.left = build(preL + 1, preL + leftSize, inL, rootIndex - 1);

        // 5. 递归构建右子树
        // 前序右子树范围：[preL + leftSize + 1, preR]
        // 中序右子树范围：[rootIndex + 1, inR]
        root.right = build(preL + leftSize + 1, preR, rootIndex + 1, inR);

        return root;
    }
}
```
