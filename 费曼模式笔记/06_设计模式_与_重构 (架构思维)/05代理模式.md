## 代理模式

* 设计模式解决的问题:
  先明确一点，代码模式的代理按照我的理解，是因为需要使用到被代理对象的某些功能，但是有对访问权限控制，原始功能增强，屏蔽不需要使用的功能，统一管理使用该对象的入口的需求的时候才需要使用代理模式。
* 真实的使用代理模式的场景

  * 1.性能优化问题，当你要加载的对象非常大的时候，但是**如高清大图、巨大的XML文件、复杂的数据库对象**，但是可能我并不需要使用这些，或者很久才会使用到，这时候就要使用虚拟代理进行懒加载延迟了。
    **做法**：先创建一个轻量级的代理对象返回给用户，只有当用户真正调用方法（如 **`display()`）时，代理才会在后台去加载那个重量级的真实对象。
    **例子****：网页中的图片懒加载，先显示一个占位图，滚动到视口才加载真实图片
  * 2.安全保护与权限控制（**保护代理**），某些核心业务对象，**（如敏感数据、管理员功能）不能让所有人都直接访问，需要根据用户的角色来判断是否有权限。**

    代理对象在接收到请求后，先检查调用者的权限（如 **`if (user.isAdmin())`）。如果有权限，就转发给真实对象；如果没有，就抛出异常或拒绝执行。
    场景：公司内部系统，普通员工只能看自己的工资条，但是HR可以看所有人的。
  * 3.远程调用问题（远程代理）
    场景：远程对象不在本地内存中，而在另外一台服务器上
    解决：使用远程代理。

    做法：代理对象存放在本地，它隐藏了网络通信的复杂性（如序列化，网络传输，Socket链接）
    例子：RPC框架（Dubbo），微服务调用，RMI。
  * 4.功能增强场景，不想修改原始对象，但是想给它做功能增强，比如日志，缓存，事务。（为了遵循开闭原则）
    解决：使用代理模式（典型例子SpringBoot的AOP）
    做法：在事务在调用真实对象前和之后插入逻辑。

    * **前置** **：记录开始时间、开启数据库事务。**
    * **后置** **：记录结束时间、提交事务、打印日志。**
  * 5.引用计数与资源管理（智能引用）
    **你需要知道一个对象被引用了多少次，以便在没人用时自动释放资源。**
    解决，使用智能代理
    **做法** **：代理对象维护一个引用计数器。每次被引用时加一，释放时减一，当计数为0时自动删除真实对象**
* java实现：

  ```java
  // 真实对象接口
  interface Image {
      void display();
  }

  // 真实对象
  class RealImage implements Image {
      private String filename;

      public RealImage(String filename) {
          this.filename = filename;
          loadFromDisk();
      }

      private void loadFromDisk() {
          System.out.println("加载图片: " + filename);
      }

      public void display() {
          System.out.println("显示图片: " + filename);
      }
  }

  // 代理对象
  class ProxyImage implements Image {
      private RealImage realImage;
      private String filename;

      public ProxyImage(String filename) {
          this.filename = filename;
      }

      public void display() {
          if (realImage == null) {
              realImage = new RealImage(filename);
          }
          realImage.display();
      }
  }

  // 使用
  public class ProxyPatternDemo {
      public static void main(String[] args) {
          Image image = new ProxyImage("test.jpg");
          image.display();  // 第一次调用会加载图片
          image.display();  // 第二次调用直接显示，不会重复加载
      }
  }
  ```
