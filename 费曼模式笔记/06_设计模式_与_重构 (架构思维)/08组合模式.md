## 组合模式

* 一句话说明白:把对象想象成树状，统一处理单个和整体，单个对象和组合对象之间存在形式上的一致性。
* 举例说明吧，以往组织结构里面，部门节点和人员节点是完全不一样的两个类型，但是如果按照组合模式来说，他们有一个共同点，都是组织结构里面某个节点的特点，提取这个共同点，按照代码语言来说，就是他们都要实现一个名字叫做组织节点的接口，这样他们才能被从结构树上访问。
* 技术应用场景，文件系统，文件和文件夹的统一处理   ||| UI组件，窗口，面板，按钮的层次结构 ，菜单系统的多级菜单


* java实现

  ```java
  // 组件接口
  interface Component {
      void operation();
  }

  // 叶子组件
  class Leaf implements Component {
      private String name;

      public Leaf(String name) {
          this.name = name;
      }

      public void operation() {
          System.out.println("叶子节点: " + name);
      }
  }

  // 组合组件
  class Composite implements Component {
      private List<Component> children = new ArrayList<>();
      private String name;

      public Composite(String name) {
          this.name = name;
      }

      public void add(Component component) {
          children.add(component);
      }

      public void remove(Component component) {
          children.remove(component);
      }

      public void operation() {
          System.out.println("组合节点: " + name);
          for (Component child : children) {
              child.operation();
          }
      }
  }

  // 使用
  public class CompositePatternDemo {
      public static void main(String[] args) {
          // 创建叶子节点
          Component leaf1 = new Leaf("叶子1");
          Component leaf2 = new Leaf("叶子2");
          Component leaf3 = new Leaf("叶子3");

          // 创建组合节点
          Composite composite1 = new Composite("组合1");
          composite1.add(leaf1);
          composite1.add(leaf2);

          Composite composite2 = new Composite("组合2");
          composite2.add(leaf3);
          composite2.add(composite1);

          // 执行操作
          composite2.operation();
      }
  }
  ```
* 代码实现解析：
  角色说明: 组件接口，统一的样式框架
  叶子组件，可以将具体的业务类包裹在里面的组件接口实现类。
  组合组件，实现了组件接口的类，里面存在一个list对象，用于存储实现了接口组件的对象，比如叶子组件或者组合组件。
