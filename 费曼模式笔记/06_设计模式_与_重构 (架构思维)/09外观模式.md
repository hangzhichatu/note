## 外观模式

* 核心思想，**给复杂系统套个"简单接口"，隐藏内部细节** **，提供统一的高层接口简化子系统使用。** 这个设计模式其实很基础 ，更像是为了协调改造老系统，老代码而在，新结构调用，和老代码API之间做的一个中间层，能够简化使用流程。**重点:对高级调用隐藏使用细节，按照预设的方法使用低级系统的服务**
* java实现
  ```java
  // 复杂子系统
  class CPU {
      public void start() {
          System.out.println("CPU启动");
      }
  }

  class Memory {
      public void load() {
          System.out.println("内存加载");
      }
  }

  class HardDrive {
      public void read() {
          System.out.println("硬盘读取");
      }
  }

  // 外观类
  class ComputerFacade {
      private CPU cpu;
      private Memory memory;
      private HardDrive hardDrive;
    
      public ComputerFacade() {
          cpu = new CPU();
          memory = new Memory();
          hardDrive = new HardDrive();
      }
    
      public void start() {
          System.out.println("开始启动计算机...");
          cpu.start();
          memory.load();
          hardDrive.read();
          System.out.println("计算机启动完成");
      }
  }

  // 使用
  public class FacadePatternDemo {
      public static void main(String[] args) {
          ComputerFacade computer = new ComputerFacade();
          computer.start();
      }
  }
  ```
