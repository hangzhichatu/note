## 模板方法模式

* 核心思想，定义"流程框架"，细节让子类填写，先定义算法步骤，再让子类实现具体细节。
* 真实技术场景:
  JDBC操作流程:固定的连接、执行、关闭流程
  业务审批流程：固定审批步骤，不同业务有不同规则
  框架设计，SpringBoot大量使用模板方法
* java示例:

  ```java

  // 抽象类定义模板方法
  abstract class Beverage {
      // 模板方法：定义算法骨架
      public final void prepare() {
          boilWater();
          brew();
          pourInCup();
          addCondiments();
      }

      // 具体方法
      private void boilWater() {
          System.out.println("烧开水");
      }

      private void pourInCup() {
          System.out.println("倒入杯中");
      }

      // 抽象方法，由子类实现
      protected abstract void brew();
      protected abstract void addCondiments();
  }

  // 具体子类
  class Tea extends Beverage {
      protected void brew() {
          System.out.println("用茶叶泡水");
      }

      protected void addCondiments() {
          System.out.println("加柠檬");
      }
  }

  class Coffee extends Beverage {
      protected void brew() {
          System.out.println("用咖啡机冲泡");
      }

      protected void addCondiments() {
          System.out.println("加糖和牛奶");
      }
  }

  // 使用
  public class TemplateMethodDemo {
      public static void main(String[] args) {
          Beverage tea = new Tea();
          Beverage coffee = new Coffee();

          System.out.println("准备茶:");
          tea.prepare();

          System.out.println("\n准备咖啡:");
          coffee.prepare();
      }
  }
  ```
* 和策略模式的混淆点
  **策略模式**:
  **核心**：****组合 (Composition) 。****  关系：一个上下文类，有一个策略接口的实例 **流程控制****：由****客户端**在创建上下文类时，决定传入哪个具体的策略实现。
