# 新建模块的笔记

* 目标 新建微服务模块，比如叫 `ruoyi-order` 注册到Nacos ，被网关通过路径 (`/order/**`)访问，从Nacos拉取自己的配置

## 创建过程

* 步骤1在项目根目录新建模块

  ```bash
  your-ruoyi-project/
  ├── ruoyi-gateway/
  ├── ruoyi-system/
  ├── ruoyi-danny/
  └── ruoyi-order/          ← 新建这个文件夹
  ```
* 步骤2 创建pom.xml 继承若依父工程

  ```xml
  <!-- ruoyi-order/pom.xml -->
  <?xml version="1.0" encoding="UTF-8"?>
  <project xmlns="http://maven.apache.org/POM/4.0.0"
           xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
           xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 
           http://maven.apache.org/xsd/maven-4.0.0.xsd">
      <modelVersion>4.0.0</modelVersion>
      <parent>
          <groupId>com.ruoyi</groupId>
          <artifactId>ruoyi</artifactId>
          <version>3.6.0</version> <!-- 与你的主项目一致 -->
      </parent>

      <artifactId>ruoyi-order</artifactId>
      <name>ruoyi-order</name>
      <description>订单微服务</description>

      <dependencies>
          <!-- Web -->
          <dependency>
              <groupId>org.springframework.boot</groupId>
              <artifactId>spring-boot-starter-web</artifactId>
          </dependency>

          <!-- Nacos 服务发现 -->
          <dependency>
              <groupId>com.alibaba.cloud</groupId>
              <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
          </dependency>

          <!-- Nacos 配置中心 -->
          <dependency>
              <groupId>com.alibaba.cloud</groupId>
              <artifactId>spring-cloud-starter-alibaba-nacos-config</artifactId>
          </dependency>

          <!-- 若依公共模块（含工具类、注解等）-->
          <dependency>
              <groupId>com.ruoyi</groupId>
              <artifactId>ruoyi-common</artifactId>
          </dependency>

          <!-- 其他你需要的依赖（如 MyBatis、Redis 等）-->
      </dependencies>
  </project>
  ```

  关键：引入 `nacos-discovery` 和 `nacos-config`

  ## 配置文件
* 步骤1 创建bootstrap.yml

  ```yaml
  # ruoyi-order/src/main/resources/bootstrap.yml

  server:
    port: 9202  # ← 注意：不要和已有服务冲突！

  spring:
    application:
      name: ruoyi-order   # ← 服务名！必须唯一

    profiles:
      active: dev         # 环境

    main:
      allow-bean-definition-overriding: true

    cloud:
      nacos:
        discovery:
          server-addr: ruoyi-nacos:8848
          namespace: 36a6cffb-6ec5-4ed8-a357-f4170e2ab131  # ← 和 gateway 一致
        config:
          server-addr: ruoyi-nacos:8848
          file-extension: yml
          namespace: 36a6cffb-6ec5-4ed8-a357-f4170e2ab131
          shared-configs:
            - application-${spring.profiles.active}.${spring.cloud.nacos.config.file-extension}
  ```
* 步骤2 在Nacos创建配置文件

    登录 Nacos 控制台 → 切换到你的命名空间（`36a6...`）→ **+号新增配置**

配置1 主配置（Data ID = `ruoyi-order-dev.yml`）

```yaml
# Data ID: ruoyi-order-dev.yml
# Group: DEFAULT_GROUP

# 日志、数据库、MyBatis 等按需配置
spring:
  datasource:
    url: jdbc:mysql://...
    username: root
    password: ...

mybatis:
  mapper-locations: classpath*:mapper/**/*.xml

# 其他业务配置...
```

编写启动类和Controller

* 步骤二 在Nacos中编辑  `ruoyi-gateway-dev.yml `找到 `spring.cloud.gateway.routes` 添加

  ```yaml
  - id: ruoyi-order
    uri: lb://ruoyi-order
    predicates:
      - Path=/order/**
    filters:
      - StripPrefix=1
  ```
