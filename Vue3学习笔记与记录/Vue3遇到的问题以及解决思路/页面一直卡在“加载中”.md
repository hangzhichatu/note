## 问题记录

* 问题来信CahBlog 项目 ，展示博客内容的页面 `fetchPosts()`方法 ，由于该方法返回的是一个Axios响应对象，结构如下
    ```javaScript
        { data: [...], status: 200, headers: {...}, config: {...} }
    ```
    所以将整个响应对象赋值给了 posts.value 模板中 v-for="post in posts" 实际在遍历一个对象，而非数组 → 无内容渲染

* 问题的查询方法：
    通过在前后端分别打印输出最终确定。  设置输出信息的点 ，前端: `onMounted()`函数  调用  `fetchPosts()`方法 的地方。目的 ，前者确保不是由于前端代码bug导致组件未加载导致的没有显示，后者确定后端的Api有正常工作，并且校验返回值是否正常

    后端: 后端，在对应的Control类 ，service类，以及security 配置类，增加输出，目的是排除 `跨域问题` `持久层问题` `token会话是否过期` `访问路径是否正确` 这几种情况

* 最终的解决，在fetchPosts方法中，先获取 return.data再返回值
