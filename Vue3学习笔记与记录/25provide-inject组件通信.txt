在 Vue 3 中，provide 和 inject 是一种跨层级组件通信的机制，适用于祖先组件向任意后代组件传递数据（无需逐层 props 透传）。它常用于插件、主题配置、全局状态等场景。
✅ 一、基本用法（Options API vs Composition API）
Vue 3 同时支持 Options API 和 Composition API，下面分别说明

1. Composition API（推荐）
📌 祖先组件（提供数据）
// Parent.vue
import { provide, ref } from 'vue';

export default {
  setup() {
    const theme = ref('dark');
    const updateTheme = (newTheme) => {
      theme.value = newTheme;
    };

    // 提供响应式数据和方法
    provide('theme', theme);
    provide('updateTheme', updateTheme);

    return { theme };
  }
};
💡 注意：如果要让 inject 的值保持响应性，必须使用 ref 或 reactive 包裹。


📌 后代组件（注入数据）
// Child.vue 或更深层的 GrandChild.vue
import { inject } from 'vue';

export default {
  setup() {
    const theme = inject('theme', 'light'); // 第二个参数是默认值
    const updateTheme = inject('updateTheme');

    return {
      theme,
      updateTheme
    };
  }
};

📌 模板中使用

<template>
  <div :class="theme">
    当前主题：{{ theme }}
    <button @click="updateTheme('light')">切换为浅色</button>
  </div>
</template>


2. Options API
祖先组件

// Parent.vue
export default {
  data() {
    return {
      theme: 'dark'
    };
  },
  provide() {
    // 注意：直接返回普通对象，响应性会丢失！
    return {
      theme: this.theme,
      updateTheme: (newTheme) => {
        this.theme = newTheme;
      }
    };
  }
};
⚠️ 问题：这样 theme 不是响应式的！后代组件无法感知变化。

✅ 解决方案：使用 this + computed（Vue 3.3+ 支持）

// Parent.vue (Options API with reactivity)
import { computed } from 'vue';

export default {
  data() {
    return { theme: 'dark' };
  },
  provide() {
    return {
      // 使用 computed 保持响应性
      theme: computed(() => this.theme),
      updateTheme: (newTheme) => {
        this.theme = newTheme;
      }
    };
  }
};

或者更推荐：在 setup 中使用 provide（混合写法）

// Parent.vue
import { provide, ref, watchEffect } from 'vue';

export default {
  setup() {
    const theme = ref('dark');
    provide('theme', theme);
    provide('updateTheme', (val) => theme.value = val);
  }
};

✅ 二、最佳实践建议

1. 使用 Symbol 作为 key（避免命名冲突）

// keys.js
export const THEME_KEY = Symbol();
export const UPDATE_THEME_KEY = Symbol();

// Parent.vue
import { THEME_KEY, UPDATE_THEME_KEY } from './keys';
provide(THEME_KEY, theme);
provide(UPDATE_THEME_KEY, updateTheme); 

// Child.vue
import { THEME_KEY, UPDATE_THEME_KEY } from './keys';
const theme = inject(THEME_KEY, 'light');
const updateTheme = inject(UPDATE_THEME_KEY);

2. 只读保护（可选）
如果你不希望子组件修改提供者的状态，可以只注入 getter：
provide('theme', readonly(theme)); // 使用 readonly 包裹
✅ 三、注意事项

问题	说明
❌ 不是响应式？	必须用 ref / reactive / computed 包裹
❌ 修改注入值？	默认不建议子组件直接修改，应通过提供者的方法更新
🔄 响应式更新	只要 provide 的是响应式对象，inject 后自动响应
