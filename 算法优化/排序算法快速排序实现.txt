#理论 #代码实现
思想:快速排序基于分治的思想，每次遍历 都能将一个元素放置其正确的位置上
其分治的依据如下，在待排序序列中，选择一个元素作为枢轴元素 一趟排序后将比枢轴元素大的放置其前面，比枢轴元素小的放在其后面
这样一个大的待排序问题就划分为两个小的待排序问题。
当每个小待排序数列的长度都为1的时候，即完成了数列的排序

代码实现思路1：
双指针法，用两个指针a1 、 a2分别指向待排序数列的最前和最后一个元素 （以从大到小排序为例）
首先指针a1指向的元素和枢轴元素对比，如果比枢轴元素小则指针往后移动一位，如果比枢轴元素大则停止移动
当指针a1停止移动的时候，指针a2开始移动类似指针a1的移动策略，如果指针a2指向的值比枢轴大指向的大则指针a2往前移动一位
当指针a2遇到比其小的元素的时候，停止移动，这时候交换指针a1和指针a2指向的元素。然后指针a1重新移动
当指针a1和指针a2指向的元素相同的时候，循环结束 （代码实现上代着每次移动都需要检验这种情况）
结束的时候返回将 递归调用方法本身传入参数开始的下标和结束的下标， 当子进程完成时候返回 1；

双指针法的一种枢轴元素选取的除了方法，可以选择末尾的元素作为枢轴元素，这样下标移动的逻辑就变成了如下：
a1和a2指向的元素做对比，如果a1元素小于a2则a1往后移动一位，如果a1元素大于a2则a1的元素和a2的元素交换位置（这个时候等价于处于末尾的枢轴元素移动到a1的位置
这个时候a1前的元素都比枢轴元素小）。交换位置后，a2接替a1移动，a2往前移动如果指向的元素比枢轴元素(现在是a1指向的元素)大则继续往前移动，如果比a1小则a2和a1指向的元素
交换位置，然后a1接替a2移动。当a1和a2指向同一个下标的时候指针移动结束。

第二种做法比起第一种优势是可以省略一个变量用来存储枢轴元素的值，其次第一种做法在指针遇到枢轴元素的时候需要做特殊操作，比如跳过枢轴元素或者采取交换指针移动的策略或者最后把枢轴元素放到a1和a2交汇的位置，缺点是无法采用枢轴元素优化策略选择可能可以避免极端情况的枢轴元素。
第二种方案被称作使用 Lomuto 分区方案 (更易理解，逻辑上更简单):


#代码 #python
def quicksort(arr, low, high):
    """
    快速排序主函数
    """
    if low < high:
        # 进行分区，返回基准的最终位置
        pi = partition(arr, low, high)
        
        # 递归排序基准左边的子数组
        quicksort(arr, low, pi - 1)
        # 递归排序基准右边的子数组
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    """
    分区函数 (Lomuto 分区方案，以最后一个元素为基准)
    """
    pivot = arr[high]  # 选择最后一个元素作为基准
    i = low - 1        # 小于基准的区域的右边界

    for j in range(low, high):
        # 如果当前元素小于或等于基准
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]  # 交换

    # 将基准放到正确位置
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1

# 使用示例
arr = [3, 6, 8, 10, 1, 2, 1]
print(f"原数组: {arr}")
quicksort(arr, 0, len(arr) - 1)
print(f"排序后: {arr}")


代码阅读理解，该代码分为两个函数，

quicksort 主函数，主要负责分治问题
partition每一趟排序调用排序函数，时间复杂度为 n 空间复杂度为常数级别， 在每次分治都取到最佳的枢轴元素的情况下
log2(n)趟排序即可完成故整体函数的时间复杂度为 nlog(n)级别

partition函数思想详细解释: 单趟排序如下，枢轴元素默认设置为尾元素 设置指针i指向小于枢轴元素的前一个元素，
循环开始，遍历整个数组 当当前遍历的元素小于或等于枢轴元素的时候 指针i往后移动一位(意思是最终比枢轴元素小的右边界又往后移动了一位)
然后把指针i所指向的对象和 当前遍历的数组的对象交换位置。核心思想是指针i指向的永远是小于枢轴元素的区域的右边界，以及 指针i取 low-1作为
初始值的处理。

当遍历完成后，将基准元素放到指针i所指向的位置的后一位，确保将枢轴元素放到正确的位置上。
