## 问答形式

* Q1 : MyBaits是什么？它和Spring Boot 如何整合？
* A:  MyBaits是一个优秀的持久层框架，它支持定制化的SQL、存储过程以及高级映射。它避免了几乎所有的JDBC代码和手动设置参数以及获取结果集的过程。
  在SpringBoot 中，通过引入 `mybatis-spring-boot-starter`依赖可以自动配置MyBaits所需的组件(如SqlSessionFactory、SqlSessionTemplate)，并且通过注解或者XML方式编写SQL。

  ```xml
  <dependency>
      <groupId>org.mybatis.spring.boot</groupId>
      <artifactId>mybatis-spring-boot-starter</artifactId>
      <version>3.0.3</version> <!-- 注意版本兼容性 -->
  </dependency>
  ```

  Spring Boot会自动读取 `application.yml` 或 `application.properties` 中的配置 如(mapper-locations、type-aliases-package等完成整合)
* Q2 :SpringBoot是如何自动配置MyBaits的
* A:
  SpringBoot 通过 `MybatisAutoConfiguration`类实现自动配置。该类会做以下操作:

  * 检查是否已存在 `SqlSessionFactory`和 `SqlSessionTemplate`Bean;
  * 若不存在，则基于 `DataSource`自动创建它们；
  * 扫描 `@Mapper`注解的接口，并注册为Mapper Bean(需配合 `@MapperScan`或在接口上加 `@Mapper`);
  * 支持配置属性绑定（如 `mybatis.mapper-locations=classpath:mapper/*.xml`）。

  关键点：`MyBatis-Spring`项目提供 `SqlSessionFactoryBean`和 `MapperScannerConfigurer`,而Spring Boot Stater将这些封装成自动配置
* Q3: @Mapper 和 @MapperScan有什么区别
* A:

  * `@Mapper`:标注在单个Mapper接口上，告诉Spring这是一个MyBaits Mapper,需要被代理实现。但每个接口都要加，繁琐。
  * `@MapperScan("com.example.mapper"))`:标注在启动类或配置类上，批量扫描指定包下的所有接口，自动注册为Mapper Bean,推荐使用。

    示例:

    ```java
    @SpringBootApplication
    @MapperScan("com.example.demo.mapper")
    public class DemoApplication {
        public static void main(String[] args) {
            SpringApplication.run(DemoApplication.class, args);
        }
    }
    ```
* Q4：MyBatis 在Spring Boot 中如何使用XML映射文件?
* A:
  步骤如下：

  * 在 `application.yml`中指定映射文件位置:

    ```yaml
    mybatis:
      mapper-locations: classpath:mapper/*.xml
      type-aliases-package: com.example.demo.entity
    ```
  * 编写mapper接口

    ```java
    public interface UserMapper {
        User selectById(Long id);
    }
    ```
  * 
  * 编写对应的XML文件（如 `UserMapper.xml`）放在 `resources/mapper/`目录下:

    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
    <mapper namespace="com.example.demo.mapper.UserMapper">
        <select id="selectById" resultType="User" parameterType="long">
            SELECT * FROM user WHERE id = #{id}
        </select>
    </mapper>
    ```
* Q5:如何在MyBatis+Spring Boot中开启事务管理器?
* A:
  Spring Boot 默认集成Spring 的声明式事务管理。只需:

  * 在启动类或者配置类上添加 `@EnableTransactionManagement` （spring boot 2.x+ 不需要手动显示添加）
  * 在Service 方法上使用 `@Transaction`注解。

  ```java
  @Service
  public class UserService {
      @Autowired
      private UserMapper userMapper;

      @Transactional
      public void transfer(Long fromId, Long toId, BigDecimal amount) {
          userMapper.deductBalance(fromId, amount);
          userMapper.addBalance(toId, amount);
      }
  }
  ```

  * 底层由Spring的 `DataSourceTransactionManager`管理事务，MyBaits的SqlSession会参与Spring事务
* Q6 : MyBaits的#{}和${}有什么区别？在Spring Boot中需要注意什么？
* A:
  `#{}`：预编译处理(PreparedStatement),防止SQL注入，推荐使用。类似于JDBC里面的?替代变量
  `${}`: 字符串替换，直接拼接SQL有注入的风险，仅用于动态表名，列名等场景。

  ```xml
  <!-- 安全 -->
  <select id="getUserByName" resultType="User">
      SELECT * FROM user WHERE name = #{name}
  </select>

  <!-- 危险，仅在必要时使用 -->
  <select id="selectByTableName" resultType="User">
      SELECT * FROM ${tableName} WHERE id = #{id}
  </select>
  ```
* Q7: 如何在Spring Boot 中配置MyBaits的分页插件(如PageHelper)?
* A：以pageHelper为例
  引入依赖:

  ```xml
  <dependency>
      <groupId>com.github.pagehelper</groupId>
      <artifactId>pagehelper-spring-boot-starter</artifactId>
      <version>1.4.6</version>
  </dependency>
  ```

  在service中使用：

  ```java
  @Service
  public class UserService {
      @Autowired
      private UserMapper userMapper;

      public PageInfo<User> getUsers(int pageNum, int pageSize) {
          PageHelper.startPage(pageNum, pageSize);
          List<User> list = userMapper.selectAll();
          return new PageInfo<>(list);
      }
  }
  ```

  PageHelper通过拦截器(Interceptor)在SQL语句执行前动态添加了LIMIT字句
* Q8: MyBatis一级缓存和二级缓存在SpringBoot中表现如何?
* A：

  * 一级缓存:sqlSession级别，默认开启。但是在SpringBoot中，每次数据库操作通常使用新的SqlSession(由SqlSessionTemplate代理),因此一级缓存基本失效
  * 二级缓存:Mapper级别，需要手动开启。在Mapper XML中添加 `<cache />`,且实体类需实现 `serializable`.但是在高并发或分布环境下，不建议开启MyBatis二级缓存，容易导致脏读。更推荐使用Redis等外部缓存。
* Q9:如何进行MyBaits的单元测试(结合Springboot)？
* A:
  使用 `@SpringBootTest`+`@AutoConfigureTestDatabase`或许H2内存数据库:
  代码演示:

  ```java
  @SpringBootTest
  @TestPropertySource(properties = {
      "spring.datasource.url=jdbc:h2:mem:testdb",
      "mybatis.mapper-locations=classpath:mapper/*.xml"
  })
  class UserMapperTest {

      @Autowired
      private UserMapper userMapper;

      @Test
      void testSelectById() {
          User user = userMapper.selectById(1L);
          assertNotNull(user);
      }
  }
  ```

  也可以使用 `@MybatisTest`(需要配合 `@AutoConfigureTestDataBase`)进行轻量级测试
* Q10 : Mybatis-plus 和原生的MyBatis 在SpringBoot中如何选择?
* A：

  * MyBatis-plus是MyBatis的增强工具,提供CRUD封装、条件构造器、分页插件等，减少样本代码，时候快速开发
  * 原生MyBatis:更灵活，适合复杂SQL场景或对SQL有精细控制需求。总而言之如果项目追求开发效率且业务相对标准，推荐 MyBatis-Plus；若 SQL 极其复杂或性能敏感，可选原生 MyBatis
