## 问题解决

* 问题说明：当后端服务启动的时候，有些时候(比如开发用的机器长期没有开机的情况下)，会出现一切涉及到数据库的处理都会发生错误，但是使用Idea手动链接数据库后，就不会有问题了。
* 问题分析：原因 1：HikariCP 连接池未预热（最常见！） Spring Boot默认使用HikariCP连接池，它默认是懒加载的，直到第一次请求时候才会创建数据库链接
但如果：
数据库配置有细微错误（如时区、SSL）
网络有延迟
驱动版本不匹配


这里配置的内容 时区相关的内容被配置到数据库的url上面
后续请求都会出错的，这种问题可以通过配置yaml配置文件简单解决:
```yaml
    spring:
        datasource:
            url: jdbc:mysql://localhost:3306/cah_blog_db?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
            username: root
            password: 123456
            driver-class-name: com.mysql.cj.jdbc.Driver
            # 👇 新增 Hikari 配置 👇
            hikari:
            minimum-idle: 1          # 启动时至少创建1个连接
            initialization-fail-timeout: 1  # 启动时连接失败立即报错（便于排查）
            connection-timeout: 30000       # 连接超时30秒
            max-lifetime: 1800000           # 连接最大存活30分钟（避免被DB kill）
```
