## 介绍静态资源常用的导入方式(特别是前端库)
* 阅读源码 `WebMvcAutoConfiguration` 这个类是webMvc的自动装配类，它定义了各种html请求等方法的，资源路径等方法的配置
    ```java
        public void addResourceHandlers(ResourceHandlerRegistry registry) {
            if (!this.resourceProperties.isAddMappings()) {
                logger.debug("Default resource handling disabled");
            } else {
                this.addResourceHandler(registry, this.mvcProperties.getWebjarsPathPattern(), "classpath:/META-INF/resources/webjars/");
                this.addResourceHandler(registry, this.mvcProperties.getStaticPathPattern(), (registration) -> {
                    registration.addResourceLocations(this.resourceProperties.getStaticLocations());
                    if (this.servletContext != null) {
                        ServletContextResource resource = new ServletContextResource(this.servletContext, "/");
                        registration.addResourceLocations(new Resource[]{resource});
                    }

                });
            }
        }
    ```
    该方法是静态资源路径的设置方法，接下来我详细解释该方法，并且最终给出静态资源的默认导出路径，以及可选的配置项的作用


    * ✅ 第 1 行：检查是否禁用默认静态资源处理
    ```java
        if (!this.resourceProperties.isAddMappings()) 
    ```
    this.resourceProperties 是 ResourceProperties 类型，对应配置属性 spring.web.resources.*
    换句话来说这个判断会读取配置文件里面的这一项

    ```yaml
        spring:
            web:
                resources:
                    add-mappings: false  # 默认是 true
    ```
    如果用户显式设置为 false，表示 “不要自动注册静态资源处理器”（比如你完全自己控制资源路径）。

    ✅ 第 3 行：开始注册 WebJars 资源
    ```java
    this.addResourceHandler(registry, this.mvcProperties.getWebjarsPathPattern(), "classpath:/META-INF/resources/webjars/");
    ```

    this.mvcProperties 是 WebMvcProperties，对应 spring.mvc.* 配置。
    getWebjarsPathPattern() 返回 WebJars 的访问路径模式，默认是："/webjars/**"

    * WebJars 是什么？
        它是把前端库（如 jQuery、Bootstrap）打包成 JAR 文件的方式。例如引入 webjars-locator-core 后，你可以通过：
        /webjars/jquery/3.6.0/jquery.min.js
        访问到 META-INF/resources/webjars/jquery/3.6.0/jquery.min.js 文件。（不必显示的将这些前端框架放到static等资源目录下面）

    * ✅ 第 4–9 行：注册通用静态资源（如 static、public 目录）
    ```java
        this.addResourceHandler(registry, this.mvcProperties.getStaticPathPattern(), (registration) -> {
            registration.addResourceLocations(this.resourceProperties.getStaticLocations());
            if (this.servletContext != null) {
                ServletContextResource resource = new ServletContextResource(this.servletContext, "/");
                registration.addResourceLocations(new Resource[]{resource});
            }
        });
    ```
    如果你没有在配置文件里面配置这一项的话,那么默认有静态资源文件夹 META_INF/resource,resource,static,public这四个（优先级排序）
    ```yaml
        spring:
            mvc:
                static-path-pattern: /static/**
    ```
